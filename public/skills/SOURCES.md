# Skill logo sources

Technology SVG logos are from Devicon: https://github.com/devicons/devicon (license included as DEVICON-LICENSE.txt). Logos and names remain trademarks of their respective owners.

Hono logo: https://hono.dev/images/logo.svg
BullMQ logo: https://bullmq.io/images/bullmq-logo.png

SQL, WebSocket, REST APIs, Pub/Sub, Machine Learning, LLM Integration, Vector Search, HNSW, DSA, and CI/CD use descriptive Lucide icons rather than implying that these concepts have official brand logos. Lucide is already a project dependency.

Assets are stored locally to avoid third-party image requests on page visits. Monochrome brand marks are adjusted for legibility on charcoal backgrounds.
